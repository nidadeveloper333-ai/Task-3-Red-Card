# Red Card 2018 - China Digital Football Awards
**Developed by: Nida Husnain**
A responsive, pixel-perfect front-end web development project showcasing the Red Card 2018 web application portal. The interface is split into two major production-ready sections: the Submission Portal and the Winners & Report Showcase.

## 🚀 Features

### Screen 1: Submission Portal
- **Clean Split Layout:** Two-column interactive interface using CSS Flexbox.
- **Dynamic Form Design:** Custom-styled input text fields, textareas, and branded selection controls.
- **Status Indication:** Embedded success banner design reflecting form submission state.
- **Creative Cuts:** Sleek angular cut corner geometry at the section bottom via clean CSS pseudo-elements (`::after`).

### Screen 2: Winners & Report Showcase
- **Hero Presentation:** Bold, impactful typography utilizing large heading structures with tailored letter spacing.
- **Fluid Grid Engine:** Fully dynamic 5-column grid system built with CSS Grid that effortlessly scales down across tablets and mobile viewports.
- **Geometric Elements:** Custom CSS-drawn decorative triangles alongside sharp diagonal geometric design cutouts to match branding aesthetics.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure (`<section>`, `<header>`, `<main>`, `<footer>`).
- **CSS3:** Modern properties including **CSS Grid**, **Flexbox**, CSS Transforms, and Custom Shapes.
- **Responsive Web Design:** Advanced media query breakpoints handling layouts perfectly across mobile, tablet, and desktop screens.
